# Documentation RGPD interne

Documents de travail du responsable de traitement. Ils ne sont pas publiés sur le site.

Le dépôt est public : n'écrire ici **aucune donnée personnelle** (pseudo, identifiant de membre, email, date de demande).
Les éléments nominatifs (registre des effacements, échanges avec les membres, notes d'incident) se gardent hors du
dépôt et hors du serveur, par exemple dans un dossier chiffré sur le PC de l'éditeur.
